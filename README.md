# Ultimate V2 — 开奖分析器

简要：基于实时抓取的开奖记录进行即时分析与回测，适用于快速探索 `特码`、`平特一肖`、`平特三连肖`、`二中二`、`胆码` 等策略权重与命中率。

**主要特点**
- 实时抓取开奖网站数据（不在本地持久化存储）
- 支持以下分析：
  - 特码（仅计最后一个号码）
  - 平特三连肖（仅计前6区的连续3期共同生肖）
  - 平特（前6区或任一区出现即算）
  - 二中二（基于前6区组合频次）
  - 胆码排名（不分区）
- 权重融合：贝叶斯、遗漏、冷热、生肖、波色、尾数、马尔可夫等启发式得分融合
- 回测：支持以“最近 N 期”为样本进行命中率回测

运行环境
- Python 3.8+
- 依赖见 `requirements.txt`

快速运行
```bash
pip install -r requirements.txt
python -m streamlit run d:\streamlit\app.py
```

界面说明
- 侧边栏：设置历史窗口大小（`历史窗口`）、选择要运行的分析项、是否启用回测与回测轮数。
- 主区域：显示最近一期开奖信息、预测候选、组合示例、分数热度柱状图，以及所选分析（特码/平特一肖/三连肖/二中二/胆码）的详细结果。

回测说明
- 回测以最近若干期为样本，模拟在每个历史时间点使用窗口内的数据预测下一期，并统计：
  - 特码 Top1 命中率
  - 平特 Top12 覆盖率（任一区出现）
  - 二中二（基于 Top8 组合）命中率

可调参数与扩展建议
- 可在 `app.py` 中调整各个模型的权重（如贝叶斯、遗漏、冷热等），以及 TopN 候选数。
- 若需按“截止日期/期号”回测，可在界面增加日期/期号输入并修改回测起点逻辑。

重要提示
- 本工具仅用于数据分析研究；请遵守当地法律法规，理性使用。
- 分析结果为统计与启发式策略的结合，不保证获利或准确性。
